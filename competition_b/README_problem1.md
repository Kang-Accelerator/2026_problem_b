# 2026 高教社杯 B 题问题 1

这是问题 1 的离线计算几何实现。它只读取自定义 JSON 案例，不连接官方模拟器，不调用 `/enter`，也不实现问题 2 至 4。

## 模型

目标区域是半径 `R` 的圆盘。程序用外接正 `N` 边形近似圆盘，因此得到的是精确可行集的保守外逼近：不会漏掉真实可行点，但面积、直径和最小包围圆半径可能略偏大。圆盘与外接多边形的 Hausdorff 误差取

`h = R * (sec(pi/N) - 1)`。

默认 `R=1800 m, N=3600`，`h` 小于 1 mm。输出同时给出 `eps_cov_m`，其至少包含 `4h` 和相对浮点容差；落在误差带内的覆盖分类标记为 `numeric_boundary`，不把近似结果冒充严格精确结论。

每个检测点的真实方位角位于示向度 `theta` 的 `[theta-delta, theta+delta]` 内。两条边界分别转为半平面，使用 Sutherland-Hodgman 逐次裁剪。角度直接用正弦和余弦处理，所以 `0/360` 跨界无需特判。

对裁剪后的凸多边形计算面积、周长、顶点集直径 `D`、最小包围圆半径 `R_min`。覆盖判定是“存在直径为 `D` 的覆盖圆”，理论条件为 `2*R_min = D`；数值实现为 `abs(D-2*R_min) <= eps_cov`。若出现 `D-2*R_min` 明显为正，结果会标记算法不一致，而不是默认为覆盖成立。

增加检测约束只会使精确可行集收缩，因此 `D` 和 `R_min` 不会增加；覆盖性质变化只按覆盖判定解释，不另设质量等级。两测点区域不作“准平行四边形必然覆盖”的假设，任意检测点数量统一实际计算 `D` 与 MEC。

第一问只保留几何量和覆盖判定。`guaranteed_clearable` 是数学/题目条件 `R_min <= 20 m`；`ready_to_clear` 是工程条件，复用 `competition_b/config.py` 中的 `SAFE_CLEAR_RADIUS_M=18 m`。这两个字段分别表示题目条件下的数学保证和工程安全条件，不构成额外的质量分级。面积只作描述性统计，不作为补测或清除判据。

固定三点锐角反例采用真实源 `G=(809.621, 34.927)`，三个成功检测点到真实源的距离均不超过1500米，示向误差均位于 `[-1°,1°]`。该案例的最终可行域恰有3个顶点，计算得到 `D=14.8970 m`、`R_min=7.7390 m`、`D-2R_min=-0.5810 m`，差值明显超过 `eps_cov=0.00274 m`，因此直径圆不能覆盖该区域；同时 `R_min<18 m`，所以 `ready_to_clear=True`。这两个判定含义不同。

会生成：

- `competition_b/results/problem1_<case_id>.png`、`.pdf` 和 `.jpg`：每案例 300 dpi 横向双面板图。左侧为完整主图，右侧专门围绕定位区域和 MEC 自动放大；2/3 点案例直接标注完整坐标，4 点及以上案例点旁只显示简短 `S_i` 编号，并在整图下方按两列给出不重叠的精确坐标清单。右图突出区域顶点、直径端点/线段、MEC 圆/圆心和穿过局部范围的误差边界，整张图只保留一个底部共享图例。两个面板均显示 `D`、`R_min` 和覆盖判定，JPG 使用 quality=95；图标题使用 JSON 中的 `display_name_zh`，机器 `case_id` 保持不变。

当前案例共 34 个：保留原 14 个案例，并追加固定随机种子 `20260910` 生成的 20 个一致合成案例，其中 2 点 12 组、3 点 6 组、4 点 2 组。全部新增案例包含 `true_source`，bearing 由源点和检测点计算后加入不超过 1 度的误差。固定三点锐角反例和10000组随机一致性测试中的成功检测点同时满足 `5 < d_i <= 1500 m`；该距离条件只用于构造符合题意的测试数据，不参与主模型可行域裁剪。

仅计算、不绘图时可加 `--no-plots`。纯扇形交没有作为主输出：有限包围盒只能给出自适应近似，不能凭触碰固定边界证明无界；因此避免把该对照误读成严格结论。

## 已知限制

1. 主模型使用外接正多边形，不是圆弧的解析裁剪；需要更严格的圆域结果时应提高 `N` 并结合 `h` 解释误差。
2. 纯扇形交可能无界，本交付不把有限框近似作为主结论。
3. 输入示向度只表示区间约束，不额外假设误差分布，也不利用有效接收半径等问题 2 至 4 的信息。
4. 近共线三点的最小包围圆退化为覆盖三点的最远点对圆。
