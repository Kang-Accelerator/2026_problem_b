# 2026 高教社杯 B 题问题 2（第一版）

这是问题2的离线可复现第一版实现：给定第一次 `direction` 观测，搜索一个保证再次收到信号、并使第二次观测后定位区域较小的第二检测点。实现不连接官方模拟器，不调用 `/enter`，也不执行 `/clear`。

## 实现边界

- 精确源集合按 `U={G∈T∩W(S1,theta1,delta): 5<d1<=1500}` 采样；同时构造 `U_bar=T∩W∩Disk(S1,1500)`，输出并标记 `conservative_outer`。
- 距离区间逐角度计算，支持跨 `0/360`、目标圆外的 `S1` 和近切线情况。
- 保证接收筛选使用 `r2 <= max(1000,d1)`，候选点不强制位于目标圆内，默认移动预算 `B=3000 m`。
- 第二次观测先判 `near`、`direction`、`no_signal`；`no_signal` 不生成虚构示向度。主评分默认使用明确标记的 `conservative_lower_bound` 接收半径模型；没有无依据的 `mean_miss`，输出为 `null`。
- `direction` 后验加入第二点的 `1500 m` 距离上界；`near` 使用第二点 `5 m` 外包；`no_signal` 只作为风险/分支测试信息。
- 候选点搜索先用粗网格与局部细化获得高评分种子，再在种子附近建立独立的区域网格。区域基础单元默认为 `candidate_step_m/2`，边界混合单元继续四分，默认最小单元为基础单元的一半。
- 每个保留单元都实际检查中心、四角和四条边中点，共 9 个位置；所有检查点必须满足 `J <= J_best + focus_epsilon_J`。`J_best` 是粗网格/局部细化搜索中通过接收检查的全部样本，使用区域绘图同一批评分源重新评分后的最小值；默认 `focus_epsilon_J=0.005`，不表述为连续全局最优值。单元模板新增点用于验证单元，不回写为连续搜索最优值。
- 接收条件与评分条件分开验证。接收认证计算矩形内任意检测位置与保守源外包内任意源位置的充分条件；评分只完成每单元 9 点检查，因此红框统一标为“优先推荐区域（离散近似）”。
- 输出边界来自保留细单元的实际并集：删除内部重复边，保留不连通分量和孔洞，不使用包围矩形、凸包或手工移动边界。`best_single_point` 仅保留为内部诊断。
- 图中用橙色星号标出近优种子、灰色空心圆标出非近优搜索点、绿色圆点标出区域单元评分检查点；颜色条直接显示原始 `J`，且 `J` 越小越优。红叉表示接收不合格检查点，空白处表示未评估；红色粗虚线只沿保留单元并集边界绘制。
- 泰勒斯圆只输出 `heuristic_reference`，不限制搜索域，也不命名为解析最优。
